# הגמל · מוניטור גיאופוליטי

לוח מחוונים חי לאירועים גיאופוליטיים במזרח התיכון: לחימה, תנועות כוחות, סחר, מחאות ודיפלומטיה — על גבי מפה, עם איתותי הסלמה ודוחות מצב.

## מקור נתונים

- **GDELT 2.0 Events** (`data.gdeltproject.org/gdeltv2`) — חינמי, ללא מפתח, מתעדכן כל 15 דקות. כל אירוע מגיע עם מיקום גיאוגרפי, שחקנים, קוד CAMEO, ציון חומרה (Goldstein), מספר אזכורים וטון.
- המפה: Leaflet + OpenStreetMap (CARTO dark tiles) — חינמי, ללא מפתח.

## ארכיטקטורה

- Cloudflare Worker + KV (חשבון Cloudflare של הבעלים, תוכנית חינמית).
- Cron כל 15 דקות: מוריד את אשכול האירועים האחרון של GDELT, מסנן למזרח התיכון (lat 12–42, lon 24–64), מסווג לקטגוריות, מזהה אשכולות הסלמה, ושומר ל-KV.
- הדשבורד נטען מה-Assets ומושך `/api/data` כל 60 שניות.

## API

- `GET /api/data` — אירועים (26 שעות), התרעות, חלונות מגמה
- `GET /api/report` — דוח מצב מובנה בעברית
- `GET /api/refresh` — הרצת אינגסציה ידנית
- `GET /api/status` — סטטוס

## פריסה מחדש

```bash
npm install
npx wrangler deploy   # דורש CLOUDFLARE_API_TOKEN
```

## כנות

האיתותים הם סיגנלים סטטיסטיים מוקדמים מנתוני חדשות פתוחים — לא תחזית ולא מידע מאומת. הנתונים בעיכוב של ~15 דקות.
