# הגמל · מוניטור גיאופוליטי + בוט התראות

לוח מחוונים חי ובוט התראות 24/7 לאירועים ביטחוניים וגיאופוליטיים במזרח התיכון: טילים, פשיטות, תקיפות ועוד — על גבי מפה ממוקמת, עם התראות מבזק מיידיות, תוויות אימות ברורות ודוחות מצב.

## בוט ההתראות (חדש)

- **סריקת מבזקים כל דקה** (`/api/flash`): מקורות מהירים בלבד — RSS של ynet / JPost / BBC / אל ג'זירה / MEE / Arab News + ערוצי טלגרם ציבוריים (רוטציה לפי דקה, ללא מפתח).
- **מנוע התראות**: דיווח תקיפתי חדש (טיל / יירוט / אזעקה / פשיטה / תקיפה / פיצוץ...) מפיק התראת מבזק עם חומרה (critical/high), אזור, ותווית "לא מאומת" כשצריך. דה-דופ לפי מזהה ולפי גזע כותרת — אותה ידיעה לא מציפה פעמיים.
- **Push לנייד**: ההתראות נשלחות דרך ntfy.sh (חינמי, ללא הרשמה) לטופיק פרטי. הטופיק נשמר כ-secret של ה-Worker (`NTFY_TOPIC`) — לא בריפו ולא בעמוד.
- **בעמוד**: פאנל "התראות מבזק", סיכוי מיקום פועם על המפה, צליל התראה (אחרי לחיצה ראשונה), ואינדיקטור "סריקה אחרונה".

## מקורות נתונים

- **GDELT 2.0 Events** — חינמי, ללא מפתח, ~15 דקות עיכוב, גיאו-ממוקד.
- **RSS חי** — ynet מבזקים, JPost, BBC ME, Al Jazeera, Middle East Eye, Arab News.
- **טלגרם ציבורי** — סריקת `t.me/s/<channel>` ללא מפתח, תווית "לא מאומת".
- **NASA FIRMS** (חדל"פ תרמיים), **USGS** (רעידות אדמה), שכבת לווין יומית NASA GIBS, מצלמות ציבוריות מאומתות.

## ארכיטקטורה

- Cloudflare Worker + KV (חשבון הבעלים, תוכנית חינמית).
- איסוף מלא כל 5 דקות (cron-job.org → `/api/refresh`, +CF cron, +רענון יזום מעמוד פתוח).
- סריקת מבזקים כל דקה (cron-job.org → `/api/flash`, +גיבוי יזום מעמוד פתוח).
- הדשבורד מושך `/api/data` כל 45 שניות.

## API

- `GET /api/data` — אירועים, התראות מבזק, מבזקים, חלונות מגמה
- `GET /api/flash` — סריקת מבזקים מהירה (מנוע ההתראות)
- `GET /api/refresh` — איסוף מלא ידני
- `GET /api/report` — דוח מצב בעברית
- `GET /api/status` — סטטוס
- `GET /api/alert-test` — push בדיקה

## פריסה

push ל-`main` מפריס אוטומטית דרך GitHub Actions (`.github/workflows/deploy.yml`, סוד `CLOUDFLARE_API_TOKEN` בריפו).

## כנות

האיתותים הם סיגנלים מוקדמים מדיווחים פתוחים — לא אישור רשמי, לא מידע מודיעיני ולא תחזית. GDELT בעיכוב ~15 דקות; שכבת ADS-B מושבתת (חסימת IP ענן); אין AIS חינמי; אין תצלומי לווין טקטיים חינמיים.
